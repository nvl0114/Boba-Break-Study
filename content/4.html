🧠 Grammar Patterns: 很 (Hěn) & Action Sentences

1. Descriptive State Patterns (Adjectives)

Use 很 (hěn), negatives, questions, and affirmative-negative forms with adjectives.

• S + 很 + Adj
• S + 不 + Adj
• S + 很 + Adj + 嗎？
• S + Adj + 不 + Adj

Answering: 很 + Adj , 不 + Adj

這 個 畫 很 好看
Zhè ge huà hěn hǎokàn.
This painting is very good-looking.

2. Action Patterns (Verbs + Objects)

Handle action patterns with adverbs, negatives, questions, and A-not-A variations.

• S + 很 + V + O
• S + 不 + V + O (back to basic pattern)
• S + 很 + V + O + 嗎
• S + V + 不 + V + O (back to basic pattern)

Answering: 很 + Adj , 不 + Adj (or responding directly to the predicate action)

我 很 喜歡 貓咪
Wǒ hěn xǐhuān māomī.
I really like cats.
