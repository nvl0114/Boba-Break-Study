The Adverb 很 (Hěn) & Descriptive Sentences

Learn how to describe states, preferences, actions, and answer with descriptive adjectives.

🧠 Grammar Patterns: Detailed Breakdown

1. Positive Adjective Pattern

S + 很 + Adj

Explanation: Used to describe a state or quality of a subject in a positive sentence. 很 (hěn) is commonly used before an adjective and works like a connector similar to “is/am/are” in English. In this structure, 很 usually does not carry strong “very” intensity.

Answering: 很 + Adj

畫很好看
Huà hěn hǎokàn.
The painting is very good-looking.

2. Negative Adjective Pattern

S + 不 + Adj

Explanation: Used to state a negative quality. Note that when using negation with adjectives, 很 (hěn) is omitted.

Answering: 不 + Adj

小孩不可愛
Xiǎohái bù kě'ài.
The child is not cute.

3. Adjective Question Pattern (嗎)

S + 很 + Adj + 嗎？

Explanation: Used to ask a yes/no question regarding an adjective state by adding the particle 嗎 at the end.

Answering: 很 + Adj (for yes) or 不 + Adj (for no)

圖片很好看嗎？
Túpiàn hěn hǎokàn ma?
Is the picture very good-looking?

4. Adjective A-not-A Question Pattern

S + Adj + 不 + Adj

Explanation: An alternative way to ask a question by repeating the adjective in its affirmative and negative forms.

Answering: 很 + Adj (for affirmative) or 不 + Adj (for negative)

工作忙不忙？
Gōngzuò máng bù máng?
Is the work busy or not busy?

5. Positive Action/Preference Pattern

S + 很 + V + O

Explanation: Used with psychological or preference verbs (like 喜歡, 愛, 想) modified by 很.

Answering: 很 + V + O (or direct affirmative response)

我很喜歡貓咪
Wǒ hěn xǐhuān māomī.
I really like cats.

6. Negative Action Pattern

S + 不 + V + O

Explanation: Reverts back to the basic action pattern when negated with 不.

Answering: 不 + V + O

他不愛狗
Tā bú ài gǒu.
He does not love dogs.

7. Action Question Pattern (嗎)

S + 很 + V + O + 嗎

Explanation: Used to ask a question about preferences or actions using the particle 嗎.

Answering: 很 + V + O or 不 + V + O

你很想我嗎？
Nǐ hěn xiǎng wǒ ma?
Do you miss me Chinese?

8. Action A-not-A Question Pattern

S + V + 不 + V + O

Explanation: Asking an action-based question by repeating the verb in affirmative and negative forms (A-not-A) and reverting back to the basic pattern.

Answering: Affirmative verb or negative verb response

你了解不了解？
Nǐ liǎojiě bù liǎojiě?
Do you understand or not understand?
