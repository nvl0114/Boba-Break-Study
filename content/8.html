GRAMMAR LESSON • 有 / 沒有

有 (Yǒu) & 沒有 (Méiyǒu)

Learn how to talk about possession, ask whether someone has something, describe completed actions, and express existence with 有.

🧠 Grammar Patterns: Detailed Breakdown

1. Positive Possession

S + 有 + O

Explanation: Used to say that someone has or possesses something. 有 means "to have".

Structure: Subject + 有 + Object

我有錢。
Wǒ yǒu qián.
I have money.

2. Negative Possession

S + 沒有 + O

Explanation: Used to say that someone does not have something. 沒有 is used to negate possession with 有.

Structure: Subject + 沒有 + Object

我沒有錢。
Wǒ méiyǒu qián.
I don't have money.

3. Possession Question with 嗎

S + 有 + O + 嗎？

Explanation: Add 嗎 at the end of a statement with 有 to ask whether someone has something.

Answer: 有 / 沒有

你有一本書嗎？
Nǐ yǒu yì běn shū ma?
Do you have a book?

4. 有沒有 A-not-A Question

S + 有沒有 + O？

Explanation: 有沒有 is an A-not-A question pattern. It literally asks whether someone has or does not have something.

Answer: 有 / 沒有

你有沒有錢？
Nǐ yǒu méiyǒu qián?
Do you have money?

5. 有 + Verb Phrase

S + 有 + V (+ O)

Explanation: 有 can be used before a verb phrase to indicate that an action has occurred or was done.

Structure: Subject + 有 + Verb + Object

我有吃六個餃子。
Wǒ yǒu chī liù ge jiǎozi.
I ate six dumplings.

6. Negative Completed Action

S + 沒有 + V (+ O)

Explanation: 沒有 can be used before a verb phrase to say that an action did not occur or was not done.

Structure: Subject + 沒有 + Verb + Object

我沒有喝一碗湯。
Wǒ méiyǒu hē yì wǎn tāng.
I did not drink a bowl of soup.

7. Completed Action Question

S + 有 + V (+ O) + 嗎？

Explanation: Used to ask whether someone has done an action. 嗎 is placed at the end of the sentence.

Answer: 有 / 沒有

你有練習英文嗎？
Nǐ yǒu liànxí Yīngwén ma?
Have you practiced English?

8. 有沒有 + Verb Phrase

S + 有沒有 + V (+ O)？

Explanation: 有沒有 can also be used to ask whether someone has done an action.

Answer: 有 / 沒有

你有沒有學習中文？
Nǐ yǒu méiyǒu xuéxí Zhōngwén?
Have you studied Chinese?

9. Answer with 有 / 沒有

有 / 沒有

Explanation: Questions using 有 or 有沒有 can be answered simply with 有 or 沒有.

Examples: 有 = yes / have / did · 沒有 = no / don't have / did not

你有錢嗎？— 有。
Nǐ yǒu qián ma? — Yǒu.
Do you have money? — Yes.

10. Existence with 有

Place + 有 + Thing / Person

Explanation: This pattern is used to say that a person or thing exists at a particular place.

Structure: Place + 有 + Thing / Person

桌子上有一根香蕉。
Zhuōzi shàng yǒu yì gēn xiāngjiāo.
There is a banana on the table.
