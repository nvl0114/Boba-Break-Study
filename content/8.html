GRAMMAR LESSON • POSSESSION & EXISTENCE

The Verb 有 (Yǒu) & Completed Actions

Learn how to express possession, negation with 沒有, completed actions, and existence at a location.

🧠 Grammar Patterns: Detailed Breakdown

1. Positive Possession Pattern

S + 有 + O

Explanation: Used to say that someone has or possesses something.

Answering: 有 + O

我有錢
Wǒ yǒu qián.
I have money.

2. Negative Possession Pattern

S + 沒有 + O

Explanation: Used to state that someone does not have something (use 沒有 instead of 不).

Answering: 沒有 + O

我沒有一個蘋果
Wǒ méiyǒu yī gè píngguǒ.
I don't have an apple.

3. Possession Question Pattern (嗎)

S + 有 + O + 嗎？

Explanation: Used to ask whether someone possesses an object by adding 嗎.

Answering: 有 or 沒有

你有一本書嗎？
Nǐ yǒu yī běn shū ma?
Do you have a book?

4. Possession A-not-A Question Pattern

S + 有沒有 + O

Explanation: Alternative question structure using 有沒有 to ask about possession.

Answering: 有 or 沒有

你有沒有五個包子？
Nǐ yǒu méiyǒu wǔ gè bāozi?
Do you have five steamed buns?

5. Completed Action Pattern

S + 有 + V (+ O)

Explanation: 有 can precede a verb phrase to indicate that an action has occurred or was completed.

Answering: 有 + V (+ O)

我有吃六個餃子
Wǒ yǒu chī liù gè jiǎozi.
I ate six dumplings.

6. Negative Completed Action Pattern

S + 沒有 + V (+ O)

Explanation: Used to indicate that an action did not occur or was not completed.

Answering: 沒有 + V (+ O)

我沒有喝一碗湯
Wǒ méiyǒu hē yī wǎn tāng.
I didn't drink a bowl of soup.

7. Existence at Location Pattern

Place + 有 + Thing / Person

Explanation: Used to indicate that a person or object exists at a specific location.

Answering: Place + 有 + Object

桌子上有一根香蕉
Zhuōzi shàng yǒu yī gēn xiāngjiāo.
There is a banana on the table.
