GRAMMAR LESSON • POSSESSION & EXISTENCE

有 / 沒有 (Yǒu / Méiyǒu)

Learn how to say what you have, what you do not have, and ask whether someone has something.

🧠 Grammar Patterns: 有 / 沒有

1. Positive 有 Pattern

S + 有 + O

Explanation: 有 (yǒu) means “to have” or “there is/are.” Use this pattern when saying that someone possesses or has something.

Structure: Subject + 有 + Object

我有錢。
Wǒ yǒu qián.
I have money.

2. Negative 沒有 Pattern

S + 沒有 + O

Explanation: 沒有 (méiyǒu) means “do not have” or “there is/are not.” It is the normal negative form of 有.

Important: Do not use 不有 to mean “do not have.” Use 沒有 instead.

我沒有錢。
Wǒ méiyǒu qián.
I don't have money.

3. 有沒有 Question

S + 有沒有 + O？

Explanation: 有沒有 is an A-not-A question pattern. It asks whether someone has something or not.

Answering: 有 = yes / have 沒有 = no / don't have

你有沒有錢？
Nǐ yǒu méiyǒu qián?
Do you have money?

4. 有 + 嗎 Question

S + 有 + O + 嗎？

Explanation: You can also use 嗎 to turn a statement with 有 into a yes/no question.

Answering: 有 or 沒有

你有錢嗎？
Nǐ yǒu qián ma?
Do you have money?

5. 有 + Food / Object

S + 有 + Food / Object

Explanation: 有 can be used with food, drinks, objects, people, and other nouns to say that someone has or possesses them.

我有餃子。
Wǒ yǒu jiǎozi.
I have dumplings.

6. 沒有 + Food / Object

S + 沒有 + Food / Object

Explanation: Use 沒有 when saying that someone does not have a particular food, object, or thing.

我沒有牛肉麵。
Wǒ méiyǒu niúròumiàn.
I don't have beef noodles.

7. 有沒有 + Food / Object

S + 有沒有 + Food / Object？

Explanation: This pattern is especially useful when asking about the availability or possession of something.

Short answers: 有。 / 沒有。

你有沒有包子？
Nǐ yǒu méiyǒu bāozi?
Do you have steamed buns?

8. 有沒有 + Different Objects

S + 有沒有 + O？

Explanation: The same pattern can be used with different nouns. The object can be food, drinks, money, books, or other things.

Example: 你有沒有菜？

你有沒有菜？
Nǐ yǒu méiyǒu cài?
Do you have vegetables?
