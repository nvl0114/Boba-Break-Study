🧩 How to Build Numbers

Good news: Mandarin numbers follow a simple pattern. Let's build them like little blocks!

1. Numbers 11–19

Put 十 (shí) first, then add the number after it.

十 + number
十一11 · shí yī
十五15 · shí wǔ
十九19 · shí jiǔ
🎂 Think of 十 as the number 10's big hat. Add 一, 五, or 九 underneath it and—ta-da!—11, 15, or 19.
2. The Tens · 20, 30, 40… 90

Put the number first, then 十 (shí).

number + 十
二十20 · èr shí
三十30 · sān shí
四十40 · sì shí
五十50 · wǔ shí
六十60 · liù shí
九十90 · jiǔ shí
3. Tens + Ones · The Number Sandwich 🥪

For numbers like 21, 32, or 94, put the tens first, 十 in the middle, and the ones at the end.

number + 十 + number
二十一21 · èr shí yī
三十二32 · sān shí èr
九十四94 · jiǔ shí sì
🥪 Example: 52 = 五 (5) + 十 (10) + 二 (2) → 五十二. Easy! The number sandwich is ready.
