GRAMMAR • 得

Describing How an Action Is Done

Learn how to use 得 (de) to describe how an action is performed.

🧠 Grammar Patterns

得 (de) is placed after a verb to describe how an action is done. There are two simple patterns to remember.

1. One-Character Verbs

Subject + Verb + 得 + Description

Rule: If the verb has one Chinese character, put 得 (de) directly after the verb.

The description tells us how the action is performed.

她寫得很漂亮。
Tā xiě de hěn piàoliang.
She writes very beautifully.

More examples:

老師講得很清楚。
Lǎoshī jiǎng de hěn qīngchǔ.
The teacher explains very clearly.
妹妹唱得很好聽。
Mèimei chàng de hěn hǎotīng.
My younger sister sings very well.
他畫得很漂亮。
Tā huà de hěn piàoliang.
He draws very beautifully.
你做得很好。
Nǐ zuò de hěn hǎo.
You do it very well.

2. Two-Character Verbs

Subject + Verb + Verb + 得 + Description

Rule: If the verb has two Chinese characters, repeat the verb before 得 (de).

For example, 跳舞 (tiàowǔ) is a two-character verb.

她跳舞跳得很好。
Tā tiàowǔ tiào de hěn hǎo.
She dances very well.

Why repeat 跳?

跳舞 → 跳舞 + 跳得 + Description

跳舞跳得很好。
Tiàowǔ tiào de hěn hǎo.
Dance very well.

The first 跳舞 keeps the original two-character verb, while the second 跳 connects the action to 得.

3. More Two-Character Verb Examples

Verb + Verb + 得 + Description
他跑步跑得很快。
Tā pǎobù pǎo de hěn kuài.
He runs very fast.
弟弟游泳游得很快。
Dìdi yóuyǒng yóu de hěn kuài.
My younger brother swims very fast.
爸爸開車開得很慢。
Bàba kāichē kāi de hěn màn.
Dad drives very slowly.
姐姐跳舞跳得很漂亮。
Jiějie tiàowǔ tiào de hěn piàoliang.
My older sister dances beautifully.

⭐ Easy Rule

1-character verb → V + 得 + Description

Examples:

寫 → 寫得很漂亮
Xiě → xiě de hěn piàoliang
講 → 講得很清楚
Jiǎng → jiǎng de hěn qīngchǔ
畫 → 畫得很好
Huà → huà de hěn hǎo
2-character verb → Verb + V + 得 + Description

Examples:

跳舞 → 跳舞跳得很好
Tiàowǔ → tiàowǔ tiào de hěn hǎo
跑步 → 跑步跑得很快
Pǎobù → pǎobù pǎo de hěn kuài
游泳 → 游泳游得很好
Yóuyǒng → yóuyǒng yóu de hěn hǎo
開車 → 開車開得很慢
Kāichē → kāichē kāi de hěn màn
唱歌 → 唱歌唱得很好聽
Chànggē → chànggē chàng de hěn hǎotīng

🧋 Quick Comparison

One-character verb

寫 (xiě) → 寫得很漂亮 (xiě de hěn piàoliang)

講 (jiǎng) → 講得很清楚 (jiǎng de hěn qīngchǔ)

畫 (huà) → 畫得很好 (huà de hěn hǎo)

Two-character verb

跳舞 (tiàowǔ) → 跳舞跳得很好 (tiàowǔ tiào de hěn hǎo)

跑步 (pǎobù) → 跑步跑得很快 (pǎobù pǎo de hěn kuài)

游泳 (yóuyǒng) → 游泳游得很好 (yóuyǒng yóu de hěn hǎo)

開車 (kāichē) → 開車開得很慢 (kāichē kāi de hěn màn)

⭐ Key idea: Look at the verb first. Is it one character or two?
