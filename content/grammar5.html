有 (yǒu) & 沒有 (méiyǒu) Have, Exist, and Actions That Happened 有 (yǒu) is one of the most common verbs in Mandarin. It has three major uses: have / has — possession there is / there are — existence 有 + Verb — indicates that an action or event happened 沒有 (méiyǒu) is the negative form of 有. Session 1 — 有 / 沒有: Have / Has Use 有 when someone has or possesses something. Positive Pattern Subject + 有 + Noun 我有哥哥。 Wǒ yǒu gēge. I have an older brother. 我有一個孩子。 Wǒ yǒu yí ge háizi. I have a child. 她有一台電腦。 Tā yǒu yì tái diànnǎo. She has a computer. Negative Use 沒有 to make 有 negative. Pattern Subject + 沒有 + Noun 我沒有哥哥。 Wǒ méiyǒu gēge. I don't have an older brother. 我沒有車。 Wǒ méiyǒu chē. I don't have a car. 📌 Important Note: 不有 is incorrect Unlike many other Mandarin verbs, 有 is not normally negated with 不. ❌ 我不有哥哥。 Wǒ bù yǒu gēge. ✅ 我沒有哥哥。 Wǒ méiyǒu gēge. So remember: 有 → 沒有 have → don't have Not: ❌ 有 → 不有 Asking with 嗎 You can use 嗎 to turn a statement into a yes/no question. Pattern Subject + 有 + Noun + 嗎？ 你有哥哥嗎？ Nǐ yǒu gēge ma? Do you have an older brother? 你有車嗎？ Nǐ yǒu chē ma? Do you have a car? Asking with 有沒有 You can also use the A-not-A pattern: Pattern Subject + 有沒有 + Noun？ 你有沒有哥哥？ Nǐ yǒu méiyǒu gēge? Do you have an older brother? 你有沒有車？ Nǐ yǒu méiyǒu chē? Do you have a car? Here: 有 = have 沒有 = don't have So: 有沒有？ = have or not have? Both forms are natural: 你有哥哥嗎？ Do you have an older brother? 你有沒有哥哥？ Do you have an older brother? How to Answer For both question patterns, you can answer: Yes 有。 Yǒu. Yes, I do. Or with a complete sentence: 有，我有一個哥哥。 Yǒu, wǒ yǒu yí ge gēge. Yes, I have an older brother. No 沒有。 Méiyǒu. No, I don't. Or: 沒有，我沒有哥哥。 Méiyǒu, wǒ méiyǒu gēge. No, I don't have an older brother. Quick Rule 有嗎？ → 有 / 沒有 有沒有？ → 有 / 沒有 Session 2 — 有 / 沒有: There Is / There Are 有 can also describe something that exists or is present in a place. In this use, the sentence usually starts with a place. Positive Pattern Place + 有 + Noun 學校有很多學生。 Xuéxiào yǒu hěn duō xuéshēng. There are many students at the school. 房間裡有一張桌子。 Fángjiān lǐ yǒu yì zhāng zhuōzi. There is a table in the room. 冰箱裡有牛奶。 Bīngxiāng lǐ yǒu niúnǎi. There is milk in the refrigerator. Negative Use 沒有 when something does not exist or is not present. Pattern Place + 沒有 + Noun 學校沒有學生。 Xuéxiào méiyǒu xuéshēng. There are no students at the school. 房間裡沒有桌子。 Fángjiān lǐ méiyǒu zhuōzi. There isn't a table in the room. Asking with 嗎 Pattern Place + 有 + Noun + 嗎？ 學校有學生嗎？ Xuéxiào yǒu xuéshēng ma? Are there students at the school? 房間裡有桌子嗎？ Fángjiān lǐ yǒu zhuōzi ma? Is there a table in the room? Asking with 有沒有 Pattern Place + 有沒有 + Noun？ 學校有沒有學生？ Xuéxiào yǒu méiyǒu xuéshēng? Are there students at the school? 房間裡有沒有桌子？ Fángjiān lǐ yǒu méiyǒu zhuōzi? Is there a table in the room? How to Answer Yes 有。 Yǒu. Yes, there is / there are. Or: 有，學校有很多學生。 Yǒu, xuéxiào yǒu hěn duō xuéshēng. Yes, there are many students at the school. No 沒有。 Méiyǒu. No, there isn't / there aren't. Or: 沒有，學校沒有學生。 Méiyǒu, xuéxiào méiyǒu xuéshēng. No, there aren't any students at the school. Quick Rule 有嗎？ → 有 / 沒有 有沒有？ → 有 / 沒有 Session 3 — 有 + Verb: An Action Happened This is an important additional use of 有. When 有 comes before a verb, it can indicate that an action or event happened or occurred. Here, 有 does not literally mean “have.” Pattern Subject + 有 + Verb (+ Object) 我有吃早餐。 Wǒ yǒu chī zǎocān. I have eaten breakfast. 他有去台北。 Tā yǒu qù Táiběi. He went / has been to Taipei. 我有看這部電影。 Wǒ yǒu kàn zhè bù diànyǐng. I have watched this movie. 你最近有認識新的朋友。 Nǐ zuìjìn yǒu rènshi xīn de péngyǒu. You have met new friends recently. The English translation depends on the context. 有 + Verb does not always correspond exactly to the English present perfect. The important idea is: 有 + Verb → indicates that the action/event happened Negative: 沒有 + Verb Use 沒有 when the action did not happen or has not happened. Pattern Subject + 沒有 + Verb (+ Object) 我沒有吃早餐。 Wǒ méiyǒu chī zǎocān. I haven't eaten breakfast. 他沒有去台北。 Tā méiyǒu qù Táiběi. He didn't go to Taipei. 我沒有看這部電影。 Wǒ méiyǒu kàn zhè bù diànyǐng. I haven't watched this movie. 我最近沒有認識新的朋友。 Wǒ zuìjìn méiyǒu rènshi xīn de péngyǒu. I haven't met any new friends recently. So: 有 + Verb → action/event happened 沒有 + Verb → action/event did not happen Asking with 嗎 Pattern Subject + 有 + Verb + Object + 嗎？ 你有吃早餐嗎？ Nǐ yǒu chī zǎocān ma? Have you eaten breakfast? 你有看這部電影嗎？ Nǐ yǒu kàn zhè bù diànyǐng ma? Have you watched this movie? 你最近有認識新的朋友嗎？ Nǐ zuìjìn yǒu rènshi xīn de péngyǒu ma? Have you met any new friends recently? Asking with 有沒有 Pattern Subject + 有沒有 + Verb + Object？ 你有沒有吃早餐？ Nǐ yǒu méiyǒu chī zǎocān? Have you eaten breakfast? 你有沒有看這部電影？ Nǐ yǒu méiyǒu kàn zhè bù diànyǐng? Have you watched this movie? 你最近有沒有認識新的朋友？ Nǐ zuìjìn yǒu méiyǒu rènshi xīn de péngyǒu? Have you met any new friends recently? How to Answer Yes 有。 Yǒu. Yes. Or: 有，我有吃早餐。 Yǒu, wǒ yǒu chī zǎocān. Yes, I have eaten breakfast. No 沒有。 Méiyǒu. No. Or: 沒有，我沒有吃早餐。 Méiyǒu, wǒ méiyǒu chī zǎocān. No, I haven't eaten breakfast. Quick Rule 有 + Verb + 嗎？ → 有 / 沒有 有沒有 + Verb？ → 有 / 沒有 Session 4 — 有 + Number + Measure Word Use 有 with a number and measure word to say how many things someone has. Pattern Subject + 有 + Number + Measure Word + Noun 我有三個朋友。 Wǒ yǒu sān ge péngyǒu. I have three friends. 她有兩個孩子。 Tā yǒu liǎng ge háizi. She has two children. 我有一台電腦。 Wǒ yǒu yì tái diànnǎo. I have one computer. Asking How Many Subject + 有 + 幾 + Measure Word + Noun？ 你有幾個朋友？ Nǐ yǒu jǐ ge péngyǒu? How many friends do you have? 你有幾個兄弟姊妹？ Nǐ yǒu jǐ ge xiōngdì jiěmèi? How many siblings do you have? Answering 我有三個朋友。 Wǒ yǒu sān ge péngyǒu. I have three friends. 我有兩個兄弟姊妹。 Wǒ yǒu liǎng ge xiōngdì jiěmèi. I have two siblings. ⭐ Quick Summary Session 1 — Have / Has S + 有 + N → I have... S + 沒有 + N → I don't have... S + 有 + N + 嗎？ → Do you have...? S + 有沒有 + N？ → Do you have...? Answer: → 有 / 沒有 📌 有 → 沒有, not 不有 Session 2 — There Is / There Are Place + 有 + N → There is / There are... Place + 沒有 + N → There isn't / There aren't... Place + 有 + N + 嗎？ → Is there / Are there...? Place + 有沒有 + N？ → Is there / Are there...? Answer: → 有 / 沒有 Session 3 — Action / Event S + 有 + V → The action happened / occurred S + 沒有 + V → The action didn't happen / hasn't happened S + 有 + V + 嗎？ → Did / Have you...? S + 有沒有 + V？ → Did / Have you...? Answer: → 有 / 沒有 Session 4 — Quantity S + 有 + Number + Measure Word + N → Someone has a certain number of things S + 有 + 幾 + Measure Word + N？ → How many...? Answer: → S + 有 + Number + Measure Word + N ⭐ One Last Thing to Remember 有 has three major meanings: 有 + Noun → have / has 我有哥哥。 Place + 有 + Noun → there is / there are 學校有學生。 有 + Verb → an action/event happened 我有吃早餐。 And the negative is always: 有 → 沒有 not: ❌ 有 → 不有
