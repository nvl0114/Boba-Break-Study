🧠 Grammar Patterns

1. Possessive Structure: Owner + 的 + Possessed Object

To show ownership or description in Mandarin, use the particle 的 (de) between the owner and the object.

Owner Noun / Pronoun
+
的 de
+
Object Noun

的 (de) acts like an apostrophe-s ('s) or possessive modifier in English (e.g., "my", "teacher's").

我 的 手機
Wǒ de shǒujī.
My mobile phone.

2. Basic Sentence: S + V + O

Mandarin basic sentences follow the Subject + Verb + Object structure using new plurals and items.

S Subject
+
V Verb
+
O Object

Subject + Verb + Object forms the foundation of statements.

我們 看 電視
Wǒmen kàn diànshì.
We watch television.

3. Negative Sentence: S + 不 + V + O

Make any sentence negative by placing 不 (bù) directly before the verb.

S Subject
+
不 not
+
V Verb
+
O Object

不 (bù) negates the action verb that follows it.

他 不 買 車
Tā bù mǎi chē.
He does not buy a car.

4. Question Particle: S + V + O + 嗎

Turn statements into Yes/No questions by appending 嗎 (ma) to the end.

Statement S + V + O
+
嗎 ma?

Add 嗎 (ma) at the end of a complete statement to ask a question.

妳們 看 報紙 嗎
Nǐmen kàn bàozhǐ ma?
Do you (female plural) read the newspaper?

5. Alternative Question: S + V + 不 + V

Ask a choice question using the Verb + 不 + Verb (A-not-A) pattern.

S Subject
+
V Verb
+
不 not
+
V Verb

Combine positive and negative verb forms to ask if an action is performed or not.

老師 買 不 買
Lǎoshī mǎi bu mǎi?
Does the teacher buy or not?
